# HW-MD4 实施计划｜铜薄膜表面台阶与初始塑性

**研究问题**：在相同铜势、晶向、温度和拉伸条件下，原子台阶会不会改变 FCC 铜薄膜首个位错出现的位置、类型和载荷？

**最小交付**：平整面与台阶面的受控对照、完整的独立运行统计、一组事件逐帧证据、一个针对主要不确定性的复核。内容按证据组织。主图预算为 7 幅，其中若干为多面板，全部重复的曲线、平衡日志和参数敏感性放附录。

## 1. 起始模型与控制变量

- 沿用 HW-MD3 的 Mishin Cu EAM1 课程文件 CuYM.eam.alloy。记录势文件校验值并随输入保存来源。
- 初案取 (001) 自由表面、面内 [110] 拉伸、沿面内 [−110] 的台阶线。以正确的右手坐标系建盒，两面内方向周期、法向自由。两组来自同一晶体，使用相同的面内尺寸与名义厚度。初案面内约 4–6 nm，厚约 6–8 nm。
- 台阶面在上表面局部移除完整原子层，构造周期相容的一对台阶。先导前记录台阶高度、走向和间距、上下面位置、原子数和名义厚度。首轮采用一个台阶高度，主实验沿用通过先导验收的几何。报告将结果限定在这个周期台阶对及其间距。
- 平整组和台阶组采用同一横向约束。为减少额外变量，初案采用面内横向盒长固定，并记录横向应力；方法中称为轴向拉伸、横向受限。自由法向允许薄膜内部松弛。台阶引入的原子数或残余应力差作为模型描述与诊断量。
- 无载能量最小化后，在 300 K 平衡。检查温度、势能、轴向及横向残余应力、表面高度轮廓和初始缺陷；若平衡仍有漂移，延长平衡并重新验收。
- 记录轴力或轴向 virial 总和、真实盒长和参考材料区域。主图用统一的参考截面给出名义应力，说明台阶组沿加载方向截面可能变化，必要时在附录用剩余材料的有效截面重算；若改归一化会改变应力排序，以应变与位置证据为主。任何含真空盒的压力都先换回相应的力，报告中的材料应力以明示的截面积计算。

## 2. 分批模拟与验收

| 批次 | 远端 LAMMPS | 本地先完成的验收 | 进入下一批的条件 |
| --- | --- | --- | --- |
| R0 连通检查 | 使用已验证的 LAMMPS 20240829.1 模块，提交一条短任务，读入势、积分、生成数据和日志。保留 Slurm 及 LAMMPS 版本信息。 | Python 能读到步数和热力学列，OVITO 能打开原子 ID、坐标和盒边界。估算每步耗时和每条轨迹的大小。 | 运行脚本可重复，输出的时间、应变和帧一致。 |
| R1 建模和平衡 | 分别生成平整和台阶结构，完成能量最小化与 300 K 平衡，保存平衡前后构型和重启点。 | 看顶部、侧面和截线，核对台阶位置、原子层数。用 PTM/CNA 与 DXA 检查内部结构，将自由表面本来就缺配位的原子单独标记。 | 台阶在加载前仍可识别，两个模型无预存的内部位错或层错。 |
| R2 四条先导 | 每组两条独立初始化，时间步先用 1 fs，工程应变率 5×10⁹ s⁻¹。到 12% 初始应变上限约 24 ps。优先在预计事件附近输出高频构型，保留重启文件。 | 对照应力、应变和逐帧缺陷。检查靠近台阶的半环是否能识别，是否在继续加载时长入晶体，和整体失稳、单纯表面扰动区分。 | 结构与载荷能对齐，事件或未观察到事件的截止状态能可靠判定。预试验后先固定判据、检测阈值和统一上限，再开正式批次。 |
| R3 主实验 | 主速率平整/台阶各 6 条独立正式轨迹。每条使用不同的速度随机种子并独立平衡，保存全部运行及最终状态。先导在方案调整后单独记录。 | 输出完整事件表、个体曲线、位置分类和事件间隔。核对事件分类有争议的帧，复核初始状态。 | 数据足以区分位置结果与载荷结果。若样本波动较大，给出差值范围和样本数。 |
| R4 复核 | 默认在 10⁹ s⁻¹ 每组各 3 条初始预算，到 12% 约 120 ps；主结果若暴露厚度或台阶间距问题，改为另一厚度或间距的同条件对照。 | 与主工况并排复核。速率复核仅改变速率；几何复核仅改变要检验的尺寸。 | 明确主结论保持、减弱、反转，或仍无法辨认。报告实际完成的复核与对应限制。 |

高频输出初案：热力学每 10–20 步，主轨迹每 100 步（0.1 ps，主速率约 0.05 个应变百分点）；必要时从同一重启点按相同参数重跑，疑似事件窗每 20–50 步输出一次。核实重跑前后曲线与事件对应，若轨迹分叉则独立报告高频轨迹。以先导实际吞吐量安排并发。若台阶预先失稳或所有事件都无法归类，先修正一次模型并复核；仍无法形成可判读对照时改用已规划的铝熔化备选。

## 3. 远端与本地的交接

- **远端负责生成原始证据**：每个算例单独目录，保存输入、种子、初始构型、平衡后构型、重启文件、热力学表、LAMMPS/Slurm 日志和 dump。dump 至少能按步数、盒子、原子 ID 和坐标对齐。登记作业编号、运行状态、势版本和输出校验值。
- **本地负责判读与报告**：复用上一级 uv 环境中的 OVITO Python 与 Matplotlib。先收到平衡和先导数据，做一套完整的导入、识别、跟踪和出图，之后再提交正式批次。原始文件保留原样，衍生表、图片、渲染配置单独存放。重启文件和完整轨迹可留远端，按需取回，正文图片和可复核的代表性帧归档到本地。
- **汇总表的一行对应一条独立轨迹**。最少记录组别、种子、实际温度、盒尺寸、应变率、事件状态、末次无事件帧、首次确认帧、对应应力、类型、位置、距最近台阶线或表面的距离、判读依据。记录信号分歧与复核结果。

## 4. 首事件判据与分析顺序

1. 先在无载构型标出上下表面、两个台阶与已存在的低配位区域。后台脚本对齐所有帧的步数、盒子、应变及应力。
2. 用 PTM/CNA 定位新出现的有序结构变化，配合 DXA 确认进入晶体的位错线、柏氏矢量和邻接层错片。Shockley 部分位错是一种预期结果，先发缺陷的实际类型由轨迹决定。面内距离按周期最小镜像求取。
3. 固定“持续出现”的判定标准。先用连续两到三帧逐步扩展的信号作为候选，按先导的时间分辨率确定具体窗口。对小半环或检测不一致的事件，回查位移、层错连接及多视角。使用首次可辨认且后续确认持续的帧定位，按上一帧到首次帧给出应变范围，同时保留此时间窗内的载荷变化。若部分轨迹没有事件，先比较同一截止应变下的发生比例和事件应变，再说明可观测事件的应力分布。
4. 预先定义台阶邻域和表面/内部分类，首选以相对初始或加载中实际台阶线的距离及滑移片连接关系作判据。改变距离阈值做一次敏感性分析。两组几何至少比较一次相同应变、且双方都未出现位错的构型，观察台阶附近是否更早出现局部相对位移。必要时先去除仿射变形。局部非仿射量是变形诊断，不直接代表应力集中或能垒。
5. 汇总每组事件位置频数、个体应变和应力及其离散程度。用应变作为共同的加载坐标，在未达到首次事件的运行上标注截止应变（右删失）。应力可能在事件附近回落，未观察到事件时不以截止应力代填。样本不足时报告效应大小和覆盖范围，判断位置和载荷两项是否有一致证据。

参考：[LAMMPS 连续形变](https://docs.lammps.org/fix_deform.html)、[LAMMPS 每原子应力的定义](https://docs.lammps.org/compute_stress_atom.html)、[OVITO DXA](https://docs.ovito.org/reference/pipelines/modifiers/dislocation_analysis.html)。
