# HW-MD4 先导实验

对比 (001) 铜薄膜的平整面和双原子层周期台阶对。面内 [110] 拉伸，横向盒长固定，自由法向 [001]。势文件使用 HW-MD3 的 CuYM.eam.alloy。原子截面为同一名义截面，应力去除真空体积并以拉伸为正。

- in.prepare 负责建模、最小化和 300 K 平衡。生产平衡初案为 30 ps。
- in.load 从独立平衡重启文件读入，在 300 K、5×10⁹ s⁻¹ 工程应变率下拉到 12%。日志每 20 步，轨迹每 100 步。
- run.slurm 支持 smoke、prepare、load。远端路径及作业编号记录在同目录。
- analyze.py 读取 dump 和日志并按步数严格对齐，输出逐帧 PTM/DXA 和最显著位错线的位置。检测到的第一条线只用于筛查，需结合层错和相邻帧确认。
- plot_audit.py 导出截面和加载诊断。使用上一级的共享 .venv。

原始轨迹和逐帧输出分别保存在 data 和 audit，图放 figures。正式报告使用完成判读的事件记录。

## 先导运行记录

R0（Slurm 65333548）已完成。台阶样品 14,000 原子，短平衡后 DXA 识别位错线数为 0，截面高差约 3.51 Å，五帧加载轨迹均与热力学日志匹配。短平衡 0.4 ps 只验证运行与数据交接，完整平衡由 prepare 批次执行。

equil-jobs.txt 记录四条 30 ps 平衡任务。远端出现 AssocMaxJobsLimit 时按账号实际并发度排队。continue_pilot.sh 在本地读取平衡后构型，检查几何、DXA 与 PTM，再独立提交对应拉伸任务。平衡诊断和首个候选位错仍需结合日志及相邻原子帧复核。正式批次应在先导判读后统一冻结横向约束、事件阈值及终止应变。

## R1 验收与 R2 接续

单进程重跑的四个 30 ps 平衡作业均退出码为 0:0。四个加载初态的 DXA 位错线与 PTM HCP 计数均为零。台阶样品高差为 3.53 Å 和 3.43 Å（按 x 分箱后用表层高度百分位估计）。平衡温度在末段接近 300 K，分块轴向应力仍有波动，将在加载组间比较中保留残余应力诊断。

续跑脚本的作业清单改由 fd 3 读取，避免 SSH 从标准输入读走后续样品。四个拉伸 ID 均写入 load-jobs.txt。flat-01 到达 12%，241 帧与应力日志对齐。7.10% 有单帧短线信号，7.15% 未检出。下自由面附近在 7.35%–7.40% 出现可连续跟踪的位错线与 HCP 原子信号。当前仅属单一样品的先导观察。统一的正式首事件判据须结合四条轨迹冻结。

## R2 完成与起始状态复核

四条拉伸均为 Slurm COMPLETED，退出码 0:0。四条各有 241 帧和 1201 条热力学记录。完整判读见 R2先导判读.md，绘图由 plot_loading_comparison.py 和 plot_event.py 生成。先导发现加载前存在约 3 ps 应力振荡，phase/ 记录相位敏感性以及高时间分辨率复核的输入和独立作业号。

复核第一次提交的两个 750 步等待作业因 `pxx` 未被热力学输出初始化而退出。修正在等待段热力学列中显式输出 `pxx`。实际批次使用 `phase/active-jobs.txt` 中的四个 ID，`phase/jobs.txt` 与 `phase/retry-jobs.txt` 保留原始提交记录。待作业结束，从本机运行 `bash pilot/phase/collect.sh <已登录的控制套接字>` 回传，验证 0–18000 步等间隔轨迹。
