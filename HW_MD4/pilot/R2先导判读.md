# 铜薄膜拉伸先导判读

研究问题是 (001) 铜薄膜的表面台阶是否改变首个可辨认位错的位置及其对应载荷。平整和双原子层台阶各有两个独立速度种子。当前配置为 300 K、沿 [110] 拉伸、横向盒长固定、工程应变率 5×10⁹ s⁻¹。加载日志每 0.02 ps 记录一次，原子轨迹每 0.1 ps 保存一次，对应相邻原子帧相差 0.05 个应变百分点。

## 加载前检查

| 样品 | 原子数 | 表层高度差（Å） | DXA 位错线数 | PTM HCP 原子数 |
| --- | ---: | ---: | ---: | ---: |
| flat-01 | 14,400 | 0.006 | 0 | 0 |
| flat-02 | 14,400 | −0.024 | 0 | 0 |
| step-01 | 14,000 | 3.534 | 0 | 0 |
| step-02 | 14,000 | 3.426 | 0 | 0 |

四个 30 ps 平衡任务均正常结束。表层高度差来自按 x 分箱的 z 坐标百分位数。末段温度接近 300 K，轴向应力的 5 ps 分块均值仍有波动。加载曲线比较应保留各样品的初始应力和名义截面定义。

7.10% 为首次 DXA 检出，日志中的最高轴向名义应力出现在 7.15%（5.991 GPa），7.35% 为持续下表面信号的第一个已保存帧。两者的位置不同，且其间应力已经开始下降。跨帧的 DXA 结果在 7.40% 给出了不同的柏氏矢量分量，因此可以连续定位下表面塑性信号，仍需核实同一线段的身份。当前采样无法给出唯一的形核应力。复核时可从平衡重启文件独立重放，用 0.02 ps 输出间隔检查 7.0%–7.55% 的变形，同时验证重放曲线与原始结果的一致性。

## 组间比较前的检查

逐条区分首次 DXA 检出、首次持续局部缺陷和应力下降的时序。台阶组还需在原子截面上定位缺陷与真实台阶的关系：上下表面位于不同 z，单凭到初始切面投影的 x 距离可能把下表面事件误判为台阶事件。两组轨迹使用相同规则复核之后，才能选择正式统计的事件定义和补充采样区间。

## 四条拉伸轨迹对照

四个作业均为 Slurm `COMPLETED`、退出码 `0:0`，每条轨迹到工程应变 12%，按照步数与热力学日志对齐 241 帧。应力峰值由完整热力学日志取最大值。

| 样品 | 日志峰值应变 / 应力 | 首次 DXA 应变 / 应力 | 逐帧位置和演化 |
| --- | --- | --- | --- |
| flat-01 | 7.15% / 5.991 GPa | 7.10% / 5.972 GPa | 上自由面短线下一帧未检出。下自由面在 7.35% 起有跨帧信号，首帧应力 5.358 GPa。 |
| flat-02 | 7.08% / 5.905 GPa | 7.70% / 4.321 GPa | 下自由面。7.70%–7.85% 可定位在相近位置，短线从 1.85 nm 增至 3.82 nm。 |
| step-01 | 5.06% / 5.299 GPa | 5.30% / 4.655 GPa | 上表面同一台阶邻域。5.20% 和 5.25% 已有邻近台阶的局部 HCP，5.30% 后位错线伸向晶内。 |
| step-02 | 5.05% / 5.279 GPa | 4.95% / 5.201 GPa | 初帧有两条短线，其中一条贴近台阶边；邻域多帧可辨，5.20% 有一帧未检出，5.45%–5.55% 又有间断，5.60% 起多条线相继向晶内发展。 |

两条台阶样品的首次 DXA 信号出现在 4.95%–5.30%，两条平整样品为 7.10%–7.70%。台阶组的峰值名义应力为 5.279–5.299 GPa，平整组为 5.905–5.991 GPa。按两条轨迹均值，先导中的峰值差约 0.66 GPa（11%）。台阶切除使原子数减少约 2.78%，双层切除区的最小几何厚度比名义厚度小约 1/18。按相同轴力和最薄截面进行几何敏感性计算，台阶峰值乘以 18/17 后为 5.590–5.611 GPa，仍低于两条平整样品。最薄截面结果反映归一化敏感性，无法给出台阶局部应力。

台阶组两条轨迹的早期缺陷都靠近加载后初始切线 x/Lx = 0.75 对应的上表面边缘。step-01 帧 106 的短线离仿射切线最近约 0.35 Å，同时 HCP 原子落在切线附近。step-02 帧 99 有一条短线的最高点距该切线约 0.09 Å，邻接帧仍能看到同一台阶边附近的信号。两点距离仅用于定位，受热涨落和台阶弛豫影响。现有数据也显示，平整样品可在应力下降后较晚才识别到持续缺陷，而台阶处的早期信号可能间断。正式批次应共用一套高频采样和判读规则，分别记录应力峰值、首次 DXA、持续扩展，保留对首次检出之后是否持续的复核。先导样本量为每组两条，峰值差和定位结果均需更多重复验证。

## 起始应力相位与复核设计

去除线性趋势后，15–30 ps 平衡段的轴向应力谱在平整组约 3.03 ps、台阶组约 2.96 ps 处有明显峰，标准差约 0.71–0.75 GPa。平衡阶段的最后一帧，四条轨迹都处于压应力，轴向名义应力约 −0.66 至 −0.90 GPa。拉伸早期（应变低于 4.9%）同样能辨认约 3 ps 振荡。0.5、1、2 ps 居中移动平均均保留台阶组低峰值的排序，但这些窗口无法独立检验起始相位。

复核从四个原始平衡重启出发，01 两种形貌都延迟 0.75 ps，02 两种形貌都延迟 1.50 ps。几何、势、热浴、拉伸速率沿用先导；在 0–9% 输出每 0.02 ps（0.01 个应变百分点）的原子帧，覆盖两组在先导中的首事件区间。记录等待期应力以及实际起始应力，并检查等待结束时有无 DXA 位错或 HCP 结构。每个延迟结果与自己的原轨迹对照。由于同一初态被复用，以及延迟会让微观轨迹自然分离，这批仅用于检验对加载起始状态的敏感性，独立重复数仍为每组两条。若 9% 没有可判读事件，按 9% 截止记录，再决定是否延长到统一上限。
